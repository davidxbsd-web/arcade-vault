## Project

Arcade Vault ("Es una plataforma para jugar online y competir por la mayor cantidad de puntos") — currently a freshly scaffolded Next.js app with no custom features implemented yet (`app/page.tsx` and `app/layout.tsx` are still the default `create-next-app` boilerplate).

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, ESLint 9 flat config.

There is no test runner configured yet.

## Working in this repo

- **Read `node_modules/next/dist/docs/` before writing Next.js code.** This project pins a Next.js version whose APIs/conventions may differ from training data (see `AGENTS.md`). Check `node_modules/next/dist/docs/01-app` for App Router guidance before assuming an API is unchanged — e.g. layouts already use the newer typed-route pattern (`LayoutProps<"/">` in `app/layout.tsx`) rather than a hand-written `{ children: React.ReactNode }` prop type.
- `AGENTS.md`'s `<!-- BEGIN/END:nextjs-agent-rules -->` block is regenerated by `next dev` (see `node_modules/next/dist/server/lib/generate-agent-files.js`). Leave it in place; don't hand-edit it out.
- Path alias `@/*` maps to the repo root (`tsconfig.json`).
